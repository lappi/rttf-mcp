# rttf-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MCP-сервер к rttf.ru из семи инструментов: пять доступны всегда,
два (уровень матча) — только при `RTTF_MCP_ALLOW_RESTRICTED`. Закрытые
robots.txt адреса не запрашиваются ни в одном режиме.

**Architecture:** Тонкая прослойка без состояния, устройство ttw-mcp.
`client.py` — единственная точка выхода в сеть, сверяет каждый запрос
(и каждый шаг редиректа) с robots.txt в хуке httpx. `policy.py` — флаг,
правила robots.txt, выбор видимых инструментов; без сети. `parsers/` —
чистые функции «HTML → dict» на сохранённых фикстурах. `server.py`
собирает сервер функцией `build_server(allow_restricted)` и описывает
контракты для модели в докстрингах.

**Tech Stack:** Python 3.11+, `mcp[cli]>=2.0` (`MCPServer`, stdio),
`httpx` (синхронный), `beautifulsoup4` на `html.parser`, `pytest`, `uv`.

**Spec:** `docs/superpowers/specs/2026-09-24-rttf-mcp-design.md`

**Статус кода в плане.** Весь код ниже прогнан до записи плана: 227
офлайн-тестов на снимке сайта 2026-09-24 и 4 smoke-теста против живого
rttf.ru — зелёные. Ключевые тесты политики проверены мутациями: снятие
проверки robots, извлечение матчей в выключенном режиме и отключение
фильтра инструментов — каждое роняет свой тест. Код переносится как есть;
расхождение с ожидаемым выводом значит, что что-то перенесено не так, а
не что план неточен.

Дополнительно найдено:

- Минус в дельтах — U+2212 «−», в рейтинге после турнира бывает ASCII
  «-1». Разделитель тысяч — апостроф: `1'189`. Пустая ячейка дельты = 0.
- Даты в сводке — словами, полными и сокращёнными: «24 марта 2013», «22
  фев 2025».
- Несуществующий профиль — настоящий HTTP 404 с `main.page404`.
  `/players/28415/` со слэшем — тоже 404: путь строится без слэша.
- В общем рейтинге стоят корпоративные команды («Компания _») — 5 из
  100 строк вершины.
- robots.txt содержит правила, которых нет в спеке: `/*?*isTours=*`,
  `/*?*isChilds=*`, `/novices`, `/names`, `/?fullver=`. Список в
  `policy.py` скопирован с сайта целиком.
- Форма сайта шлёт фильтры массивом (`metro[]=386`); буква правила
  `/*?*metro=*` его не ловит. Проверка сравнивает строку без `[]` —
  строже буквы, по намерению владельца.

## Отклонения от спеки

Каждое — следствие замеров или противоречия внутри спеки. Решения
приняты в пользу более строгого прочтения; их стоит подтвердить при
ревью плана.

1. **`search_players` нет ни в одном режиме.** Спека (§3) требует читать
   только разрешённые адреса «в обоих режимах», §10 запрещает обход
   «ни в одном из режимов», а поиск по имени на сайте возможен только
   через закрытые `?name=` и `/search`. Разрешённой замены нет: в
   sitemap нет имён, полный обход окнами — больше 1350 запросов, и на
   равных рейтингах он всё равно неполон. Выход на игрока — через
   `list_players` и итоговые таблицы турниров.
2. **Категории «нерабочая рука» на сайте не найдено.** Вкладки профиля:
   `rat_s` (rttf), `rat_d` (пары, своего рейтинга нет — `dfn` пуст),
   `rat_f` (ФНТР). Код `h` в фильтре турниров означает «форовые», не руку.
   Категории разбираются по вкладкам; неизвестный код отдаётся как есть,
   а не угадывается. Игровая рука — поле анкеты `playing_hand`.
3. **`list_players(city, max_rating)` вместо `page`** — листание окнами
   по рейтингу (замер 6).
4. **`search_tournaments(city, hall_id, tournament_type)` без
   `with_results`** — такого фильтра у сайта нет; ответ всегда разделён на
   `upcoming` и `past`.
5. **`get_player_matches` и `get_head_to_head` видят только последние
   10 турниров и 10 лучших побед** — предел разрешённой страницы. Оба
   докстринга говорят это прямо.
6. **`collect.py` не переносится** — многозапросных инструментов нет.
7. **Новая ошибка `PolicyViolation`** — попытка запросить закрытый адрес;
   всегда дефект сервера.

## Global Constraints

- Python `>=3.11`. Зависимости только: `mcp[cli]>=2.0`, `httpx>=0.28`,
  `beautifulsoup4>=4.12`, `soupsieve>=2.1`. `lxml` не добавлять.
- MCP SDK 2.x: `from mcp.server.mcpserver import MCPServer`. `FastMCP` и
  `mcp.server.fastmcp` в 2.x нет.
- BeautifulSoup — всегда через `soup_of(html)` = `BeautifulSoup(html, "html.parser")`.
- Базовый URL `https://rttf.ru` (не `m.rttf.ru`). Путь сущности — без
  хвостового слэша: `/players/28415`. Таймаут 30.0 с, один повтор только
  на сетевую ошибку.
- User-Agent: `rttf-mcp/0.1 (+https://github.com/lappi/rttf-mcp)`.
  Никакой маскировки под браузер.
- Запросы строго последовательны: никакого `asyncio.gather`, `ThreadPool`.
- Закрытые robots.txt адреса не запрашиваются ни в одном режиме.
  Единственная точка выхода в сеть — `RttfClient`.
- Флаг — только переменная окружения `RTTF_MCP_ALLOW_RESTRICTED`, не
  параметр инструмента.
- Идентификаторы — строки из цифр, `fullmatch` по `[1-9][0-9]{0,8}`.
- Даты наружу — ISO `YYYY-MM-DD`. Рейтинги — `int`, дельты и бонусы —
  `float`, счётчики — `int`.
- Отсутствие ключа — «не запрашивали» (например, `matches` без флага);
  `null` — «запрашивали, на сайте нет».
- Сегодняшнее значение — суффикс `_current`, значение на момент турнира
  — `_at_event` (`rating_before_event`/`rating_after_event` для таблиц).
- Проверяемые поля в тестах — только индексацией, не `.get()`.
- ФИО не попадают в код, тесты, коммиты. Фикстуры — вне git.
- Контакты залов и турниров (телефоны, имена сотрудников) не извлекаются.

## Review Focus

Входы, которые спека подразумевает, а пользователь встретит раньше всего.
Для каждого тест уже есть в задаче-владельце.

1. **Флаг выставлен как `0` или `false`.** Ожидание: закрытое выключено,
   а не «непустая строка — значит включено». Опечатка вроде `ture` —
   отказ запуска с понятным сообщением, а не молчаливый выбор режима.
   → Задача 2, `test_flag_off_values`, `test_unrecognised_flag_refuses_to_start`.
2. **Модель листает `list_players` до конца.** Ожидание: окна
   перекрываются, а не теряют игроков; на ста равных рейтингах курсор
   честно останавливается (`stalled_on_tie`), а не крутится на месте;
   `max_rating=0` отвергается до сети, потому что сайт вернул бы вершину.
   → Задачи 7 и 9, `test_next_window_overlaps_instead_of_skipping`,
   `test_window_of_equal_ratings_is_reported_as_stalled`,
   `test_invalid_input_is_refused_before_the_network[list_players-kwargs7]`.
3. **Профиль с неполным набором категорий** (только пары, без ФНТР,
   новичок с отрицательным рейтингом). Ожидание: отсутствующая категория
   — отсутствующий ключ, отрицательный рейтинг читается со знаком, пустая
   дельта — 0.0. → Задача 6, `test_doubles_only_profile_has_no_singles_key`,
   `test_beginner_ratings_go_negative_and_reset`.
4. **Аргумент с мусором**: `"28415\n"`, `True` вместо числа,
   `"r77&name=x"` в городе. Ожидание: `InvalidInput` до обращения к сети,
   в том числе без протечки закрытого параметра в запрос. → Задача 9,
   `test_invalid_input_is_refused_before_the_network`.
5. **Сайт перенаправляет на закрытый адрес.** Ожидание: редирект не
   выполняется, `PolicyViolation`. → Задача 3,
   `test_redirect_to_a_closed_address_is_not_followed`.

`rttf_mcp/errors.py`:

```python
"""Типы ошибок rttf-mcp.

Главное требование: потребитель — языковая модель, поэтому сломанный
парсер обязан отличаться от честно пустого результата.
"""


class RttfError(Exception):
    """Общий предок всех ошибок rttf-mcp."""


class InvalidInput(RttfError):
    """Аргумент инструмента не прошёл проверку; запрос не отправлялся."""


class NotFound(RttfError):
    """Сайт ответил, но запрошенной сущности нет."""


class ParseError(RttfError):
    """Разметка не совпала с ожидаемой — вероятно, сайт изменился."""

    def __init__(self, parser: str, selector: str, detail: str = "") -> None:
        self.parser = parser
        self.selector = selector
        self.detail = detail
        message = f"{parser}: не найден селектор {selector!r}"
        if detail:
            message = f"{message} ({detail})"
        super().__init__(message)


class UpstreamError(RttfError):
    """Сетевой сбой или неуспешный HTTP-код от rttf.ru."""

    def __init__(self, url: str, reason: str) -> None:
        self.url = url
        self.reason = reason
        super().__init__(f"запрос к {url} не удался: {reason}")


class PolicyViolation(RttfError):
    """Сервер попытался запросить адрес, закрытый robots.txt.

    Это всегда ошибка в коде сервера, а не во входных данных: закрытые
    адреса не запрашиваются ни в одном режиме, и клиент отказывает до
    обращения к сети.
    """

    def __init__(self, url: str, rule: str) -> None:
        self.url = url
        self.rule = rule
        super().__init__(f"адрес {url} закрыт правилом robots.txt {rule!r}; запрос не отправлялся")

"""Что сервер готов отдавать: флаг, закрытые категории, правила robots.txt.

Решение вынесено из server.py, чтобы читать его в одном месте и проверять
без сети.

Два правила, и они независимы:

1. Адреса. Сервер запрашивает только то, что разрешает robots.txt, — в
   обоих режимах. Клиент проверяет каждый адрес функцией `blocking_rule`
   до обращения к сети. Флаг на это правило не влияет.
2. Категории данных. Сайт закрыл матчи, очные встречи и поиск по имени.
   Флаг RTTF_MCP_ALLOW_RESTRICTED решает, извлекаем ли мы данные уровня
   матча, когда они попались на разрешённой странице (профиль игрока).
   При выключенном флаге инструменты этой категории не регистрируются
   вовсе.
"""

import os
import re
from collections.abc import Iterable, Mapping
from urllib.parse import unquote

FLAG = "RTTF_MCP_ALLOW_RESTRICTED"

_TRUE = frozenset({"1", "true", "yes", "on"})
_FALSE = frozenset({"", "0", "false", "no", "off"})

# Дословно из https://rttf.ru/robots.txt, снято 2026-09-24. Порядок как на
# сайте. При обновлении — копировать целиком, не пересказывать.
ROBOTS_DISALLOW: tuple[str, ...] = (
    "/actions",
    "/blacklist",
    "/changes",
    "/error",
    "/finances",
    "/likes",
    "/login",
    "/markers",
    "/messages",
    "/metro",
    "/names",
    "/notes",
    "/novices",
    "/ratings",
    "/ratscoms",
    "/ratshalls",
    "/recovery",
    "/search",
    "/settings",
    "/send",
    "/?ajax*",
    "/*/edit",
    "/*?*sort=*",
    "/*?*order=*",
    "/*?*date_from=*",
    "/*?*date_to=*",
    "/*?*name=*",
    "/*?*title=*",
    "/*?*metro=*",
    "/*?*isChilds=*",
    "/*?*isTours=*",
    "/comments",
    "/games",
    "/results",
    "/rivals",
    "/?fullver=",
)

# Инструменты уровня матча и поиска по имени: имя -> основание запрета.
# search_players здесь нет сознательно: поиск по имени на сайте возможен
# только через закрытый адрес (?name=, /search), а закрытые адреса не
# запрашиваются ни в каком режиме. См. раздел «Отклонения от спеки» плана.
RESTRICTED_TOOLS: dict[str, str] = {
    "get_player_matches": "Disallow: /games, /results — отдельные матчи",
    "get_head_to_head": "Disallow: /rivals — очные встречи",
}


class FlagError(ValueError):
    """Значение флага не распознано: сервер не запускается, а не гадает."""


def restricted_allowed(environ: Mapping[str, str] | None = None) -> bool:
    """Читает флаг. Неизвестное значение — ошибка запуска.

    Молча трактовать «maybe» или опечатку «ture» как выключенный флаг значит
    запустить сервер не в том режиме, в каком его настраивали; трактовать как
    включённый — открыть закрытое без явного согласия. Поэтому отказ.
    """
    env = os.environ if environ is None else environ
    raw = env.get(FLAG, "").strip().lower()
    if raw in _TRUE:
        return True
    if raw in _FALSE:
        return False
    raise FlagError(
        f"{FLAG}={env.get(FLAG)!r} не распознано; "
        f"включить: {sorted(_TRUE)}, выключить: {sorted(_FALSE - {''})} или не задавать"
    )


def _compile(rule: str) -> re.Pattern[str]:
    # Синтаксис robots.txt: префиксное совпадение, "*" — любая
    # последовательность, "$" в конце — якорь. Остальное литерально.
    anchored = rule.endswith("$")
    body = rule[:-1] if anchored else rule
    pattern = ".*".join(re.escape(part) for part in body.split("*"))
    return re.compile(pattern + ("$" if anchored else ""))


_COMPILED = tuple((rule, _compile(rule)) for rule in ROBOTS_DISALLOW)
_ARRAY_SUFFIX = re.compile(r"\[\]=")


def blocking_rule(path: str, query: str = "") -> str | None:
    """Правило robots.txt, закрывающее адрес, или None, если адрес открыт.

    query — строка запроса без «?», как она уйдёт в сеть. Сравнение идёт
    по раскодированной строке, в которой у имён параметров снят суффикс
    «[]»: форма самого сайта шлёт фильтр метро как metro[]=386, и буква
    правила /*?*metro=* его бы не поймала, хотя намерение владельца —
    закрыть именно этот фильтр. Проверка строже буквы, но не слабее.
    """
    plain = _ARRAY_SUFFIX.sub("=", unquote(query))
    target = path + (f"?{plain}" if plain else "")
    for rule, compiled in _COMPILED:
        if compiled.match(target):
            return rule
    return None


def tools_to_register(names: Iterable[str], allow_restricted: bool) -> list[str]:
    """Какие из инструментов сервера показывать модели."""
    names = list(names)
    unknown = set(RESTRICTED_TOOLS) - set(names)
    if unknown:
        # Опечатка в имени закрытого инструмента здесь молча открыла бы его:
        # фильтр по несовпадающему имени ничего не отфильтрует.
        raise ValueError(f"закрытые инструменты не найдены среди инструментов сервера: {sorted(unknown)}")
    if allow_restricted:
        return names
    return [name for name in names if name not in RESTRICTED_TOOLS]

"""HTTP-доступ к rttf.ru.

Клиент ничего не знает о разметке — он отдаёт текст, а разбирают его
парсеры. Запросы последовательны: сайт отвечает за 1–3 секунды, и
параллельные пачки ему ни к чему.

Каждый исходящий запрос — включая шаги перенаправления — сверяется с
robots.txt (policy.blocking_rule) в хуке httpx до отправки. Закрытое не
запрашивается ни в каком режиме, и отказ живёт в единственной точке
выхода в сеть, а не на совести каждого инструмента.
"""

from types import TracebackType

import httpx

from rttf_mcp.errors import NotFound, PolicyViolation, UpstreamError
from rttf_mcp.policy import blocking_rule


def _guard(request: httpx.Request) -> None:
    rule = blocking_rule(request.url.path, request.url.query.decode("ascii"))
    if rule is not None:
        raise PolicyViolation(str(request.url), rule)


class RttfClient:
    BASE_URL = "https://rttf.ru"
    USER_AGENT = "rttf-mcp/0.1 (+https://github.com/lappi/rttf-mcp)"
    TIMEOUT = 30.0

    def __init__(
        self,
        base_url: str = BASE_URL,
        timeout: float = TIMEOUT,
        transport: httpx.BaseTransport | None = None,
    ) -> None:
        self._timeout = timeout
        self._client = httpx.Client(
            base_url=base_url,
            timeout=timeout,
            headers={"User-Agent": self.USER_AGENT},
            transport=transport,
            follow_redirects=True,
            event_hooks={"request": [_guard]},
        )

    def get_html(self, path: str, params: dict[str, str | list[str]] | None = None) -> str:
        # Полный адрес с параметрами: в сообщении об ошибке он нужен целиком,
        # иначе непонятно, какой именно запрос не прошёл.
        url = str(self._client.build_request("GET", path, params=params or {}).url)
        last: Exception | None = None
        for _ in range(2):  # один повтор, только на сетевую ошибку
            try:
                response = self._client.get(path, params=params or {})
            except httpx.TransportError as exc:
                last = exc
                continue
            except httpx.RequestError as exc:
                # Цикл редиректов и битая кодировка лежат РЯДОМ с
                # TransportError, а не под ним, и повтор их не лечит. Но выйти
                # наружу они обязаны как UpstreamError: вызывающий ловит
                # RttfError, и сырое httpx-исключение прошло бы мимо всей
                # типизации ошибок.
                raise UpstreamError(url, f"{type(exc).__name__}: {exc}") from exc
            if response.status_code == 404:
                raise NotFound(f"{response.url} — страница не найдена")
            if response.status_code >= 400:
                raise UpstreamError(str(response.url), f"HTTP {response.status_code}")
            return response.text
        raise UpstreamError(
            url, f"{type(last).__name__}: {last} — две попытки, таймаут {self._timeout} с"
        )

    def close(self) -> None:
        self._client.close()

    def __enter__(self) -> "RttfClient":
        return self

    def __exit__(
        self,
        exc_type: type[BaseException] | None,
        exc: BaseException | None,
        tb: TracebackType | None,
    ) -> None:
        self.close()
```

```python
"""Хелперы, общие для всех парсеров rttf.ru.

Все функции чистые: принимают строку или узел, возвращают значение, в сеть
не ходят.

Особенности записи чисел на сайте, замеренные 2026-09-24:
- минус в дельтах — знак U+2212 «−», а в рейтинге после турнира бывает и
  ASCII «-» (профиль 226194: «<dfn>-1</dfn>»);
- разделитель тысяч — апостроф: «1'189», «134'555»;
- пустая ячейка дельты означает ноль (рейтинг до и после совпадает).

Неразрывный пробел и минус записываются экранированно ("\\xa0",
"\\u2212"): литеральные символы в исходнике невидимы или неотличимы от
дефиса и теряются при копировании.
"""

import re
from typing import Any, TypeVar

from bs4 import BeautifulSoup

from rttf_mcp.errors import NotFound, ParseError

T = TypeVar("T")

_MINUS = "−"
_DATE = re.compile(r"(\d{2})\.(\d{2})\.(\d{4})")
_INT = re.compile(r"[+-]?\d+")
_NUMBER = re.compile(r"[+-]?\d+(?:\.\d+)?")
_WIN_LOSS = re.compile(r"(\d+)\s*-\s*(\d+)")
_SCORE = re.compile(r"^(\d+)\s*:\s*(\d+)$")
_ID = re.compile(r"(?:^|/)(players|tournaments|halls|items)/(\d+)(?:[?#]|$)")
_RU_DATE = re.compile(r"(\d{1,2})\s+([а-яё]+)\.?\s+(\d{4})", re.IGNORECASE)
# Сводка профиля пишет месяц полностью в родительном падеже («24 марта
# 2013»), сводка пар — сокращённо («22 фев 2025»). Сличение по трём первым
# буквам покрывает обе формы; «май»/«мая» расходятся уже на третьей.
_MONTHS = {
    "янв": 1, "фев": 2, "мар": 3, "апр": 4, "май": 5, "мая": 5,
    "июн": 6, "июл": 7, "авг": 8, "сен": 9, "окт": 10, "ноя": 11, "дек": 12,
}


def soup_of(html: str) -> BeautifulSoup:
    return BeautifulSoup(html, "html.parser")


def clean(text: str) -> str:
    """Схлопывает пробелы и неразрывные пробелы, обрезает края."""
    return re.sub(r"\s+", " ", text.replace("\xa0", " ")).strip()


def _normalise_number(text: str) -> str:
    return clean(text).replace(_MINUS, "-").replace("'", "").replace(" ", "")


def parse_date(text: str) -> str:
    """DD.MM.YYYY -> YYYY-MM-DD."""
    match = _DATE.search(text)
    if match is None:
        raise ParseError("parse_date", "DD.MM.YYYY", f"получено {text!r}")
    day, month, year = match.groups()
    return f"{year}-{month}-{day}"


def parse_ru_date(text: str) -> str:
    """'24 марта 2013' | '22 фев 2025' -> YYYY-MM-DD."""
    match = _RU_DATE.search(clean(text))
    if match is None:
        raise ParseError("parse_ru_date", "Д месяц ГГГГ", f"получено {text!r}")
    day, month_word, year = match.groups()
    month = _MONTHS.get(month_word.lower()[:3])
    if month is None:
        raise ParseError("parse_ru_date", "месяц", f"неизвестный месяц {month_word!r}")
    return f"{year}-{month:02d}-{int(day):02d}"


def parse_int(text: str) -> int:
    """Целое со знаком: '1'189' -> 1189, '−18' -> -18, '-1' -> -1."""
    match = _INT.search(_normalise_number(text))
    if match is None:
        raise ParseError("parse_int", "целое", f"получено {text!r}")
    return int(match.group())


def parse_delta(text: str) -> float:
    """Изменение рейтинга: '+0.2' -> 0.2, '−18.8' -> -18.8, '' -> 0.0.

    Пустая ячейка — это ноль, а не отсутствие данных: сайт не пишет «0».
    Замерено на профиле 226194, турнир 243702: рейтинг до 12, после 12,
    итоговая ячейка пуста.
    """
    normalised = _normalise_number(text)
    if not normalised:
        return 0.0
    match = _NUMBER.fullmatch(normalised)
    if match is None:
        raise ParseError("parse_delta", "±число", f"получено {text!r}")
    return float(match.group())


def parse_win_loss(text: str) -> tuple[int, int]:
    """'3 - 1' | '800 - 389' | '87-42' -> (победы, поражения)."""
    match = _WIN_LOSS.search(_normalise_number(text).replace("(", " ").replace(")", " "))
    if match is None:
        raise ParseError("parse_win_loss", "В - П", f"получено {text!r}")
    return int(match.group(1)), int(match.group(2))


def parse_score(raw: str) -> tuple[int | None, int | None, str]:
    """Счёт матча '3 : 0' -> (3, 0, 'win').

    Исход: 'win' (N > M), 'loss' (N <= M) или 'unparsed' — форма, которой
    в замерах не было, то есть изменившаяся вёрстка. Технических
    результатов в замерах RTTF не встретилось; если появятся, они придут
    как 'unparsed' с исходной записью в score_raw, а не будут угаданы.
    """
    match = _SCORE.match(clean(raw))
    if match is None:
        return None, None, "unparsed"
    score_for, score_against = int(match.group(1)), int(match.group(2))
    return score_for, score_against, "win" if score_for > score_against else "loss"


def parse_minutes(text: str) -> int | None:
    """'12 мин.' -> 12; пустая ячейка -> None (сайт длительность не знает)."""
    cleaned = clean(text)
    if not cleaned:
        return None
    return parse_int(cleaned)


def extract_id(href: str, kind: str) -> str:
    """Числовой идентификатор из ссылки вида 'players/28415?type=d'."""
    for match in _ID.finditer(href):
        if match.group(1) == kind:
            return match.group(2)
    raise ParseError("extract_id", f"{kind}/<id>", f"получено {href!r}")


def raise_if_not_found(soup: BeautifulSoup, what: str) -> None:
    """Страница 404 сайта: main.page404. Сайт отдаёт её с кодом 404, но
    проверка по разметке страхует от ответа 200 с той же страницей."""
    if soup.select_one("main.page404") is not None:
        raise NotFound(f"{what} — страница не найдена")


def require(node: T | None, selector: str, parser: str) -> T:
    """Якорь: нет узла — значит вёрстка изменилась, а не данных нет."""
    if node is None:
        raise ParseError(parser, selector)
    return node


def text_of(node: Any) -> str:
    """Очищенный текст узла BeautifulSoup."""
    return clean(node.get_text())
```

```python
"""Разбор страницы турнира /tournaments/<id>.

Уровень турнира открыт целиком: метаданные и итоговая таблица. Матчей
на странице нет — этапы (section.tour-stage-N) выложены картинками, а
«список игр» ведёт на закрытый /games (у пар — /gamesd, под тем же
правилом).

Замерено 2026-09-24:
- section.tour-header: time «ДД.ММ.ГГГГ<br>день<br>ЧЧ:ММ», h1 с лимитом
  в var, h3 — название;
- section.tour-desc: kbd «заявилось/лимит», «Клуб: a[href^=halls/]»,
  «Адрес: mark», картинка i-doubles-*.svg у парного турнира;
- section.tour-results есть только у сыгранного турнира. Одиночная
  таблица — table.tour-players, парная — table.tour-doubles (без дельты и
  рейтинга после: сайт их для пар не публикует).
"""

import re

from bs4 import Tag

from rttf_mcp.errors import ParseError
from rttf_mcp.parsers.common import (
    clean,
    extract_id,
    parse_date,
    parse_delta,
    parse_int,
    parse_win_loss,
    raise_if_not_found,
    require,
    soup_of,
    text_of,
)

PARSER = "parse_tournament"

_TIME = re.compile(r"\b(\d{1,2}:\d{2})\b")
_REGISTERED = re.compile(r"^(\d+)(?:\s*/\s*(\d+))?$")
_COUNTS = {
    "participants": re.compile(r"Участников:\s*(\d+)"),
    "pairs": re.compile(r"Пар:\s*(\d+)"),
    "players": re.compile(r"Игроков:\s*(\d+)"),
    "games": re.compile(r"Игр:\s*(\d+)"),
}
_AVERAGE = re.compile(r"Средний рейтинг[^:]*:\s*([\d.]+)")
_COEFFICIENT = re.compile(r"Коэффициент турнира:\s*([\d.]+)")


def parse_tournament(html: str, tournament_id: str) -> dict:
    soup = soup_of(html)
    raise_if_not_found(soup, f"/tournaments/{tournament_id}")
    header = require(soup.select_one("section.tour-header"), "section.tour-header", PARSER)
    desc = require(soup.select_one("section.tour-desc"), "section.tour-desc", PARSER)
    # Части разделены <br>: без разделителя get_text склеил бы их в
    # «20.09.2026воскресенье16:00», и время не нашлось бы.
    when = clean(require(header.find("time"), "section.tour-header time", PARSER).get_text(" "))
    time_match = _TIME.search(when)
    limit_node = header.select_one("h1 var")
    hall_link = desc.select_one('a[href^="halls/"]')

    tournament: dict = {
        "tournament_id": tournament_id,
        "title": text_of(require(header.find("h3"), "section.tour-header h3", PARSER)),
        "date": parse_date(when),
        "start_time": time_match.group(1) if time_match else None,
        "limit": text_of(limit_node) if limit_node is not None else None,
        "doubles": desc.select_one('img[src*="i-doubles"]') is not None,
        "hall": (
            {"hall_id": extract_id(hall_link["href"], "halls"), "name": text_of(hall_link)}
            if hall_link is not None
            else None
        ),
        "address": _labelled_mark(desc, "Адрес"),
    }
    tournament["registered"], tournament["registration_limit"] = _registered(desc)

    results = soup.select_one("section.tour-results")
    tournament["has_results"] = results is not None
    summary = text_of(results) if results is not None else ""
    for key, pattern in _COUNTS.items():
        match = pattern.search(summary)
        tournament[key] = int(match.group(1)) if match else None
    average = _AVERAGE.search(summary)
    coefficient = _COEFFICIENT.search(summary)
    tournament["average_rating"] = float(average.group(1)) if average else None
    tournament["coefficient"] = float(coefficient.group(1)) if coefficient else None

    if results is None:
        tournament["standings"] = []
    elif tournament["doubles"]:
        table = require(results.select_one("table.tour-doubles"), "table.tour-doubles", PARSER)
        tournament["standings"] = [_doubles_row(row) for row in table.select("tbody tr")]
    else:
        table = require(results.select_one("table.tour-players"), "table.tour-players", PARSER)
        tournament["standings"] = [_singles_row(row) for row in table.select("tbody tr")]
    if results is not None and not tournament["standings"]:
        raise ParseError(PARSER, "итоговая таблица tbody tr", "секция результатов есть, строк нет")
    return tournament


def _labelled_mark(desc: Tag, label: str) -> str | None:
    for p in desc.find_all("p"):
        if text_of(p).startswith(f"{label}:"):
            mark = p.find("mark")
            return text_of(mark) if mark is not None else None
    return None


def _registered(desc: Tag) -> tuple[int | None, int | None]:
    kbd = desc.find("kbd")
    if kbd is None:
        return None, None
    match = _REGISTERED.match(text_of(kbd))
    if match is None:
        raise ParseError(PARSER, "section.tour-desc kbd", f"получено {text_of(kbd)!r}")
    return int(match.group(1)), int(match.group(2)) if match.group(2) else None


def _games_and_sets(games_cell: Tag, sets_cell: Tag) -> dict:
    wins, losses = parse_win_loss(text_of(games_cell))
    sets_won, sets_lost = parse_win_loss(text_of(sets_cell))
    return {"wins": wins, "losses": losses, "sets_won": sets_won, "sets_lost": sets_lost}


def _singles_row(row: Tag) -> dict:
    cells = row.find_all("td")
    if len(cells) < 8:
        raise ParseError(PARSER, "table.tour-players tr td ×8", f"найдено {len(cells)}")
    player = require(cells[1].find("a", href=True), "td a[href^=players/]", PARSER)
    return {
        "place": parse_int(text_of(cells[0])),
        "player_id": extract_id(player["href"], "players"),
        "name": text_of(player),
        "city": text_of(cells[2]) or None,
        "rating_before_event": parse_int(text_of(cells[3])),
        "rating_delta": parse_delta(text_of(cells[4])),
        "rating_after_event": parse_int(text_of(cells[5])),
    } | _games_and_sets(cells[6], cells[7])


def _doubles_row(row: Tag) -> dict:
    cells = row.find_all("td")
    if len(cells) < 5:
        raise ParseError(PARSER, "table.tour-doubles tr td ×5", f"найдено {len(cells)}")
    pair = []
    for a in cells[1].select('a[href^="players/"]'):
        dfn = a.find_next_sibling("dfn")
        pair.append(
            {
                "player_id": extract_id(a["href"], "players"),
                "name": text_of(a),
                "rating_at_event": parse_int(text_of(dfn)) if dfn is not None and text_of(dfn) else None,
            }
        )
    if len(pair) != 2:
        raise ParseError(PARSER, "table.tour-doubles пара a ×2", f"найдено {len(pair)}")
    return {
        "place": parse_int(text_of(cells[0])),
        "pair": pair,
        "pair_rating_at_event": parse_int(text_of(cells[2])),
    } | _games_and_sets(cells[3], cells[4])
```

"""Разбор профиля игрока /players/<id>.

Страница смешивает две категории данных, которые сайт разделяет в
robots.txt: уровень турнира (место, рейтинг до и после, баланс побед)
открыт, уровень матча (соперник, счёт, длительность, дельта за матч)
закрыт. Флаг include_matches решает, извлекается ли второй уровень; при
False его ключей в ответе нет вовсе, а парсер не касается строк матчей.

Устройство страницы, замерено 2026-09-24:
- section.player-info — ФИО, город, разряд, рука, инвентарь, вкладки
  категорий ul#tabs li[data-tab=rat_X];
- main.players > section.rat_X — содержимое категории X. Состав разный:
  rat_s: максимум, график, сводка, лучшие победы, результаты; rat_d:
  сводка и результаты, своего рейтинга нет (dfn пуст); rat_f (ФНТР):
  только максимум и график.
- В результатах — не больше 10 последних турниров категории; «все
  результаты» ведут на закрытый /results.
"""

import re

from bs4 import Tag

from rttf_mcp.errors import ParseError
from rttf_mcp.parsers.common import (
    clean,
    extract_id,
    parse_date,
    parse_delta,
    parse_int,
    parse_minutes,
    parse_ru_date,
    parse_score,
    parse_win_loss,
    raise_if_not_found,
    require,
    soup_of,
    text_of,
)

PARSER = "parse_player"

# Коды вкладок, чей смысл установлен замером. Остальные коды из списка
# data-tabs (h, p, m, w, r) в замерах не встретились ни разу: их смысл не
# угадывается, категория отдаётся под своим кодом с подписью сайта.
KNOWN_CATEGORIES = {"s": "одиночный разряд", "d": "парный разряд", "f": "рейтинг ФНТР"}

_CHART = re.compile(r"chartAll(Labels|Data)_(\w)\s*=\s*(\[[^\]]*\])")
_PLACE = re.compile(r"(\d+)\s*место")
_MAX = re.compile(r"\(([^)]*)\)")
_HALL_COUNT = re.compile(r"турниров:\s*(\d+)")
_EQUIPMENT = {"Основание": "blade", "Накладка справа": "rubber_right", "Накладка слева": "rubber_left"}
_INFO_FIELDS = {"город": "city", "Разряд": "sports_rank", "Игровая рука": "playing_hand"}


def parse_player(html: str, player_id: str, *, include_matches: bool) -> dict:
    soup = soup_of(html)
    raise_if_not_found(soup, f"/players/{player_id}")
    info = require(soup.select_one("section.player-info"), "section.player-info", PARSER)
    name = text_of(require(info.find("h1"), "section.player-info h1", PARSER))
    tabs = require(info.select_one("ul#tabs"), "section.player-info ul#tabs", PARSER)

    profile: dict = {"player_id": player_id, "name": name}
    fields = _labelled_fields(info)
    for label, key in _INFO_FIELDS.items():
        profile[key] = fields.get(label)
    profile["equipment"] = _equipment(info)

    charts = _charts(html)
    categories: dict[str, dict] = {}
    for tab in tabs.select("li[data-tab]"):
        code = tab["data-tab"].removeprefix("rat_")
        section = require(
            soup.select_one(f"main.players > section.rat_{code}"),
            f"main.players > section.rat_{code}",
            PARSER,
        )
        categories[code] = _category(code, tab, section, charts, include_matches)
    if not categories:
        raise ParseError(PARSER, "ul#tabs li[data-tab]", "у профиля нет ни одной категории рейтинга")
    profile["categories"] = categories
    if include_matches:
        wins = soup.select("main.players > section.rat_s section.player-wins tbody tr.all")
        profile["best_wins"] = [_best_win(row) for row in wins]
    return profile


def _labelled_fields(info: Tag) -> dict[str, str]:
    fields = {}
    for p in info.find_all("p", recursive=False):
        strong = p.find("strong")
        text = text_of(p)
        if strong is None or ":" not in text:
            continue
        fields[text.split(":", 1)[0].strip()] = text_of(strong)
    return fields


def _equipment(info: Tag) -> dict:
    found: dict = {key: None for key in _EQUIPMENT.values()}
    for p in info.find_all("p", recursive=False):
        label = text_of(p).split(":", 1)[0].strip()
        key = _EQUIPMENT.get(label)
        if key is None:
            continue
        link = require(p.find("a", href=True), f"{label}: a[href^=items/]", PARSER)
        found[key] = {"item_id": extract_id(link["href"], "items"), "name": text_of(link)}
    return found


def _charts(html: str) -> dict[str, dict[str, list]]:
    """Полная история рейтинга из встроенного скрипта графика.

    Массивы chartAllLabels_X и chartAllData_X — это JavaScript-литералы из
    строк и целых; разбираются регулярками, без eval.
    """
    charts: dict[str, dict[str, list]] = {}
    for kind, code, body in _CHART.findall(html):
        items = [item.strip() for item in body.strip("[]").split(",") if item.strip()]
        if kind == "Labels":
            values: list = [item.strip('"') for item in items]
        else:
            values = [int(item) for item in items]
        charts.setdefault(code, {})[kind] = values
    return charts


def _history(code: str, charts: dict) -> list[dict]:
    chart = charts.get(code)
    if chart is None:
        return []
    labels, data = chart.get("Labels", []), chart.get("Data", [])
    if len(labels) != len(data):
        raise ParseError(PARSER, f"chartAll*_{code}", f"подписей {len(labels)}, значений {len(data)}")
    # Первая подпись бывает пустой: это стартовый рейтинг до первого
    # турнира, у него нет даты.
    return [
        {"date": parse_date(label) if label else None, "rating": rating}
        for label, rating in zip(labels, data)
    ]


def _category(code: str, tab: Tag, section: Tag, charts: dict, include_matches: bool) -> dict:
    dfn = tab.find("dfn")
    rating_text = text_of(dfn) if dfn is not None else ""
    category: dict = {
        "label": KNOWN_CATEGORIES.get(code, clean(tab.find(string=True) or "")),
        "rating_current": parse_int(rating_text) if rating_text else None,
    }
    maximum = section.select_one(f"span#maxAll_{code}")
    if maximum is not None:
        category["rating_max"] = parse_int(text_of(require(maximum.find("dfn"), f"#maxAll_{code} dfn", PARSER)))
        date_match = _MAX.search(text_of(maximum))
        date_text = date_match.group(1).strip() if date_match else ""
        category["rating_max_date"] = parse_date(date_text) if date_text else None
    else:
        category["rating_max"] = None
        category["rating_max_date"] = None
    category["rating_history"] = _history(code, charts)

    stats = section.select_one("section.player-stats")
    category["stats"] = _stats(stats) if stats is not None else None

    results = section.select_one("section.player-results")
    if results is None:
        category["recent_tournaments"] = None
        category["recent_tournaments_truncated"] = None
    else:
        doubles = code == "d"
        tournaments = _results(results, doubles=doubles, include_matches=include_matches)
        category["recent_tournaments"] = tournaments
        played = category["stats"]["tournaments_played"] if category["stats"] else None
        category["recent_tournaments_truncated"] = (
            played > len(tournaments) if played is not None else None
        )
    return category


def _stats(section: Tag) -> dict:
    cells = [text_of(td) for td in section.find_all("td")]
    pairs = dict(zip(cells[0::2], cells[1::2]))
    stats: dict = {
        "rank_position": None,
        "tournaments_played": None,
        "games": None,
        "wins": None,
        "losses": None,
        "first_tournament_date": None,
        "most_frequent_hall": None,
    }
    for label, value in pairs.items():
        if label.startswith("Место в рейтинге"):
            stats["rank_position"] = parse_int(value)
        elif label.startswith("Сыграно турниров"):
            stats["tournaments_played"] = parse_int(value)
        elif label.startswith("Игры") or label.startswith("Игр "):
            stats["games"] = parse_int(value.split("(")[0])
            stats["wins"], stats["losses"] = parse_win_loss(value)
        elif label.startswith("Первый турнир"):
            stats["first_tournament_date"] = parse_ru_date(value)
    hall_link = section.select_one('a[href^="halls/"]')
    if hall_link is not None:
        count = _HALL_COUNT.search(text_of(hall_link.parent))
        stats["most_frequent_hall"] = {
            "hall_id": extract_id(hall_link["href"], "halls"),
            "name": text_of(hall_link),
            "tournaments": int(count.group(1)) if count else None,
        }
    if stats["tournaments_played"] is None:
        raise ParseError(PARSER, "section.player-stats td «Сыграно турниров»")
    return stats


def _results(section: Tag, *, doubles: bool, include_matches: bool) -> list[dict]:
    tournaments = []
    link: Tag | None = None
    participants: int | None = None
    for child in section.children:
        if not isinstance(child, Tag):
            continue
        if child.name == "a" and child.get("href", "").startswith("tournaments/"):
            link, participants = child, None
        elif child.name == "kbd" and link is not None:
            participants = parse_int(text_of(child))
        elif child.name == "table" and link is not None:
            parse = _doubles_entry if doubles else _singles_entry
            tournaments.append(parse(link, participants, child, include_matches))
            link = None
    return tournaments


def _heading(link: Tag) -> dict:
    """'20.09.2026 16:00 <var>отк</var> NEO TTA' -> дата, время, лимит, зал."""
    var = link.find("var")
    limit = text_of(var) if var is not None else None
    before, _, after = clean(link.get_text(" ")).partition(limit or "\0")
    parts = before.split()
    return {
        "tournament_id": extract_id(link["href"], "tournaments"),
        "date": parse_date(parts[0]),
        "start_time": parts[1] if len(parts) > 1 else None,
        "limit": limit,
        "hall_name": clean(after) or None,
    }


def _place(header: Tag) -> int | None:
    for i in header.find_all("i"):
        match = _PLACE.search(text_of(i))
        if match:
            return int(match.group(1))
    return None


def _footer(table: Tag) -> Tag:
    # Итоговая строка лежит прямо в table, после tbody.
    rows = table.find_all("tr", recursive=False)
    return require(rows[-1] if rows else None, "table > tr (итог турнира)", PARSER)


def _singles_entry(link: Tag, participants: int | None, table: Tag, include_matches: bool) -> dict:
    header = require(table.select_one("thead tr td"), "thead tr td (шапка турнира)", PARSER)
    footer = _footer(table)
    ths = footer.find_all("th")
    if len(ths) < 3:
        raise ParseError(PARSER, "table > tr th ×3 (итог турнира)", f"найдено {len(ths)}")
    gift = header.select_one("i.gift")
    entry = _heading(link) | {
        "participants": participants,
        "place": _place(header),
        "rating_before_event": parse_int(text_of(require(header.find("dfn"), "шапка dfn", PARSER))),
        "rating_after_event": parse_int(text_of(require(footer.find("dfn"), "итог dfn", PARSER))),
        "rating_delta": parse_delta(text_of(ths[1])),
        "bonus": parse_delta(text_of(gift)) if gift is not None else None,
    }
    entry["wins"], entry["losses"] = parse_win_loss(text_of(ths[0]))
    if include_matches:
        entry["duration_minutes_total"] = parse_minutes(text_of(ths[2]))
        entry["matches"] = [_singles_match(row) for row in table.select("tbody tr")]
    return entry


def _singles_match(row: Tag) -> dict:
    cells = row.find_all("td")
    if len(cells) < 7:
        raise ParseError(PARSER, "tbody tr td ×7 (матч)", f"найдено {len(cells)}")
    opponent = require(cells[2].find("a", href=True), "td a[href^=players/] (соперник)", PARSER)
    score_raw = text_of(cells[4])
    score_for, score_against, result = parse_score(score_raw)
    return {
        "start_time": text_of(cells[0]) or None,
        "stage": text_of(cells[1]) or None,
        "opponent_id": extract_id(opponent["href"], "players"),
        "opponent_name": text_of(opponent),
        "opponent_rating_at_event": parse_int(text_of(require(cells[3].find("dfn"), "td dfn (рейтинг соперника)", PARSER))),
        "score_for": score_for,
        "score_against": score_against,
        "score_raw": score_raw,
        "result": result,
        "rating_delta": parse_delta(text_of(cells[5])),
        "duration_minutes": parse_minutes(text_of(cells[6])),
    }


def _pair(cell: Tag) -> list[dict]:
    people = []
    for a in cell.select('a[href^="players/"]'):
        dfn = a.find_next_sibling("dfn")
        people.append(
            {
                "player_id": extract_id(a["href"], "players"),
                "name": text_of(a),
                "rating_at_event": parse_int(text_of(dfn)) if dfn is not None and text_of(dfn) else None,
            }
        )
    if len(people) != 2:
        raise ParseError(PARSER, "пара: a[href^=players/] ×2", f"найдено {len(people)}")
    return people


def _doubles_entry(link: Tag, participants: int | None, table: Tag, include_matches: bool) -> dict:
    header_cells = require(table.select_one("thead tr"), "thead tr (шапка пары)", PARSER).find_all("td")
    if len(header_cells) < 2:
        raise ParseError(PARSER, "thead tr td ×2 (шапка пары)", f"найдено {len(header_cells)}")
    pair = _pair(header_cells[0])
    footer_ths = _footer(table).find_all("th")
    if len(footer_ths) < 2:
        raise ParseError(PARSER, "table > tr th ×2 (итог пары)", f"найдено {len(footer_ths)}")
    entry = _heading(link) | {
        "participants": participants,
        "place": _place(header_cells[0]),
        "pair": pair,
        "pair_rating_at_event": parse_int(text_of(require(header_cells[1].find("dfn"), "шапка пары dfn", PARSER))),
    }
    entry["wins"], entry["losses"] = parse_win_loss(text_of(footer_ths[0]))
    if include_matches:
        entry["duration_minutes_total"] = parse_minutes(text_of(footer_ths[1]))
        entry["matches"] = [_doubles_match(row) for row in table.select("tbody tr")]
    return entry


def _doubles_match(row: Tag) -> dict:
    cells = row.find_all("td")
    if len(cells) < 6:
        raise ParseError(PARSER, "tbody tr td ×6 (парный матч)", f"найдено {len(cells)}")
    score_raw = text_of(cells[4])
    score_for, score_against, result = parse_score(score_raw)
    return {
        "start_time": text_of(cells[0]) or None,
        "stage": text_of(cells[1]) or None,
        "opponents": _pair(cells[2]),
        "opponents_pair_rating_at_event": parse_int(text_of(require(cells[3].find("dfn"), "td dfn (сумма пары)", PARSER))),
        "score_for": score_for,
        "score_against": score_against,
        "score_raw": score_raw,
        "result": result,
        "duration_minutes": parse_minutes(text_of(cells[5])),
    }


def _best_win(row: Tag) -> dict:
    cells = row.find_all("td")
    if len(cells) < 7:
        raise ParseError(PARSER, "section.player-wins tr td ×7", f"найдено {len(cells)}")
    link = require(cells[0].find("a", href=True), "лучшая победа: a[href^=tournaments/]", PARSER)

        "limit": heading["limit"],

"""Разбор списков: игроки /players/ и турниры /tournaments/.

Ни у одного списка нет разрешённой пагинации: кнопки «ещё» ходят на
закрытый /?ajax, параметр page сайт игнорирует. Замерено 2026-09-24.

Игроки листаются окнами по рейтингу (rat_to). Окно сравнивается с
ВНУТРЕННИМ дробным рейтингом, а показывается округлённое целое: при
rat_to=990 игрок с показанным 990 и внутренним 990.4 в выдачу не
попадает. Поэтому следующее окно начинается с «наименьший показанный + 1»
— с перекрытием, а не с пропуском.
"""

import re

from bs4 import Tag

from rttf_mcp.errors import ParseError
from rttf_mcp.parsers.common import (
    extract_id,
    parse_date,
    parse_int,
    require,
    soup_of,
    text_of,
)

PAGE_SIZE = 100

_CITY = re.compile(r"cities\[\]=(\w+)")
_DATE_ROW = re.compile(r"(\d{2}\.\d{2}\.\d{4})")
_REGISTERED = re.compile(r"^(\d+)(?:\s*/\s*(\d+))?$")
_TOTAL = re.compile(r"итого:\s*(\d+)")


def parse_players_list(html: str, max_rating: int | None) -> dict:
    """Строки списка игроков и курсор следующего окна.

    max_rating — верхняя граница, с которой запрашивали окно (None —
    вершина рейтинга). Нужна, чтобы распознать застревание: если все сто
    строк окна имеют один и тот же рейтинг, следующее окно совпало бы с
    текущим, и сайт отдал бы те же сто строк.
    """
    parser = "parse_players_list"
    soup = soup_of(html)
    table = require(soup.select_one("section.players-list > table"), "section.players-list > table", parser)
    players = [_player_row(row, parser) for row in table.find_all("tr") if row.find("td")]
    if len(players) < PAGE_SIZE:
        return {"players": players, "next_max_rating": None, "stalled_on_tie": False}
    next_max = min(p["rating"] for p in players) + 1
    stalled = max_rating is not None and next_max >= max_rating
    return {
        "players": players,
        "next_max_rating": None if stalled else next_max,
        "stalled_on_tie": stalled,
    }


def _player_row(row: Tag, parser: str) -> dict:
    cells = row.find_all("td")
    if len(cells) < 6:
        raise ParseError(parser, "section.players-list tr td ×6", f"найдено {len(cells)}")
    link = require(cells[1].find("a", href=True), "td a[href^=players/]", parser)
    city_link = cells[3].find("a", href=True)
    city = None
    if city_link is not None and text_of(city_link):
        match = _CITY.search(city_link["href"])
        city = {"city_id": match.group(1) if match else None, "name": text_of(city_link)}
    name = text_of(link)
    return {
        "rank": parse_int(text_of(cells[0])),
        "player_id": extract_id(link["href"], "players"),
        "name": name,
        # Корпоративные команды стоят в общем рейтинге наравне с людьми и
        # помечены хвостом « _» в имени: «Компания _». Замерено: 5 из 100
        # строк вершины.
        "is_team": name.endswith(" _"),
        "city": city,
        "rating": parse_int(text_of(require(cells[4].find("dfn"), "td dfn (рейтинг)", parser))),
        "updated": parse_date(text_of(cells[5])),
    }


def parse_tournaments_list(html: str) -> dict:
    """Ближайшие и прошедшие турниры: по сотне строк, без листания."""
    parser = "parse_tournaments_list"
    soup = soup_of(html)
    upcoming = require(
        soup.select_one("section.tours-list:not(.tours-list2) > table"),
        "section.tours-list:not(.tours-list2) > table",
        parser,
    )
    past = require(soup.select_one("section.tours-list2 > table"), "section.tours-list2 > table", parser)
    upcoming_rows, upcoming_total = _tournament_rows(upcoming, parser)
    past_rows, past_total = _tournament_rows(past, parser)
    return {
        "upcoming": upcoming_rows,
        "upcoming_total": upcoming_total,
        "upcoming_truncated": _truncated(upcoming_rows, upcoming_total),
        "past": past_rows,
        "past_total": past_total,
        "past_truncated": _truncated(past_rows, past_total),
    }


def _truncated(rows: list, total: int | None) -> bool:
    # Строку «итого: N» сайт выводит, когда список короче своего потолка;
    # тогда она и есть ответ. Без неё полная сотня означает: дальше есть,
    # но достать нельзя — подгрузка идёт через закрытый /?ajax.
    if total is not None:
        return total > len(rows)
    return len(rows) >= PAGE_SIZE


def _tournament_rows(table: Tag, parser: str) -> tuple[list[dict], int | None]:
    rows = []
    total: int | None = None
    current_date: str | None = None
    for tr in table.find_all("tr", recursive=False):
        classes = tr.get("class") or []
        if "date" in classes:
            match = _DATE_ROW.search(text_of(tr))
            if match is None:
                raise ParseError(parser, "tr.date th", f"получено {text_of(tr)!r}")
            current_date = parse_date(match.group(1))
            continue
        if not tr.has_attr("onclick"):
            summary = _TOTAL.search(text_of(tr))
            if summary is not None:
                total = int(summary.group(1))
            elif tr.find("td", recursive=False) is not None:
                raise ParseError(parser, "tr[onclick] | tr.date | «итого: N»", f"получено {text_of(tr)!r}")
            continue  # шапка из th
        cells = tr.find_all("td", recursive=False)
        if len(cells) < 6:
            raise ParseError(parser, "tr[onclick] td ×7", f"найдено {len(cells)}")
        if current_date is None:
            raise ParseError(parser, "tr.date перед строкой турнира")
        link = require(cells[2].find("a", href=True), "td a[href^=tournaments/]", parser)
        link_classes = " ".join(link.get("class") or [])
        registered, limit = _registered(cells[4], parser)
        average = text_of(cells[3])
        games = text_of(cells[5])
        rows.append(
            {
                "tournament_id": extract_id(link["href"], "tournaments"),
                "date": current_date,
                "start_time": text_of(cells[0]) or None,
                "limit": text_of(cells[1]) or None,
                "hall_name": text_of(link),
                "doubles": "doubles" in link_classes,
                "ladder": "ladder" in link_classes,
                "live": "live" in classes,
                "registration_open": "reg" in classes,
                "average_rating": parse_int(average) if average else None,
                "registered": registered,
                "registration_limit": limit,
                "games": parse_int(games) if games else None,
            }
        )
    return rows, total


def _registered(cell: Tag, parser: str) -> tuple[int | None, int | None]:
    text = text_of(cell)
    if not text:
        return None, None
    match = _REGISTERED.match(text)
    if match is None:
        raise ParseError(parser, "td kbd (заявки)", f"получено {text!r}")
    return int(match.group(1)), int(match.group(2)) if match.group(2) else None
```

"""Разбор страницы зала /halls/<id>.

Контакты зала (section.hall-info mark[itemprop=telephone]) не
извлекаются намеренно: там имена и личные телефоны сотрудников, а
модели для вопросов о рейтинге они не нужны.
"""

from bs4 import Tag

from rttf_mcp.errors import ParseError
from rttf_mcp.parsers.common import (
    extract_id,
    parse_int,
    raise_if_not_found,
    require,
    soup_of,
    text_of,
)

PARSER = "parse_hall"


def parse_hall(html: str, hall_id: str) -> dict:
    soup = soup_of(html)
    raise_if_not_found(soup, f"/halls/{hall_id}")
    info = require(soup.select_one("section.hall-info"), "section.hall-info", PARSER)
    name = text_of(require(info.select_one("h1[itemprop=name]"), "section.hall-info h1[itemprop=name]", PARSER))
    address = info.select_one("mark[itemprop=address]")
    fields = _marked_fields(info)
    site = _labelled_link(info, "Официальный сайт")
    representative = _labelled_link(info, "Представитель на сайте")
    tables = fields.get("Кол-во столов")
    hall: dict = {
        "hall_id": hall_id,
        "name": name,
        "address": text_of(address) if address is not None else None,
        "metro": [text_of(i) for i in info.select("p i.m")] or None,
        "opening_hours": fields.get("Время работы"),
        "tables": parse_int(tables) if tables else None,
        "website": site["href"] if site is not None else None,
        "representative_player_id": (
            extract_id(representative["href"], "players") if representative is not None else None
        ),
    }
    hall["amenities"], hall["paid_amenities"] = _amenities(info)
    hall["rating"] = _rating(soup.select_one("section.hall-rating"))
    return hall


def _marked_fields(info: Tag) -> dict[str, str]:
    fields = {}
    for p in info.find_all("p", recursive=False):
        mark = p.find("mark")
        text = text_of(p)
        if mark is not None and ":" in text:
            fields[text.split(":", 1)[0].strip()] = text_of(mark)
    return fields


def _labelled_link(info: Tag, label: str) -> Tag | None:
    for p in info.find_all("p", recursive=False):
        if text_of(p).startswith(f"{label}:"):
            return p.find("a", href=True)
    return None


def _amenities(info: Tag) -> tuple[list[str], list[str]]:
    # Удобства — значки i[title] в одном абзаце; платные идут после слова
    # «Платно:». Порядок сохраняется как на сайте.
    for p in info.find_all("p", recursive=False):
        icons = p.select("i[title]")
        if not icons or p.select_one("i.m") is not None:
            continue
        free, paid, is_paid = [], [], False
        for node in p.children:
            if isinstance(node, str) and "Платно" in node:
                is_paid = True
            elif isinstance(node, Tag) and node.name == "i" and node.get("title"):
                (paid if is_paid else free).append(node["title"])
        return free, paid
    return [], []


def _rating(section: Tag | None) -> dict | None:
    if section is None:
        return None
    overall = require(section.select_one("h2 dfn"), "section.hall-rating h2 dfn", PARSER)
    aspects = {}
    for row in section.select("tr"):
        cells = row.find_all("td")
        if len(cells) < 3:
            raise ParseError(PARSER, "section.hall-rating tr td ×3", f"найдено {len(cells)}")
        aspects[text_of(require(cells[0].find("b"), "section.hall-rating td b", PARSER))] = float(text_of(cells[2]))
    return {"overall": float(text_of(overall)), "aspects": aspects}
```

def _reporting(fn):
    """Доносит ошибки проекта до модели.

    SDK превращает всё, кроме ToolError, в безликое "Error executing tool
    <name>", и тогда ParseError теряет имя селектора, а NotFound становится
    неотличим от падения сайта. Перевод делаем здесь: errors.py и parsers/
    остаются свободны от зависимости на MCP.
    """

    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        try:
            return fn(*args, **kwargs)
        except RttfError as exc:
            raise ToolError(f"{type(exc).__name__}: {exc}") from exc

    return wrapper


def _valid_id(value: str, field: str) -> str:
    if not isinstance(value, str) or not _ID.fullmatch(value):
        raise InvalidInput(f"{field} должен быть числом из адреса сайта, например 28415; получено {value!r}")
    return value


def _valid_city(value: str) -> str | None:
    cleaned = (value or "").strip()
    if not cleaned:
        return None
    if not _CITY.fullmatch(cleaned):
        raise InvalidInput(
            f"city — код региона вида r77 или числовой код города вида 2; получено {value!r}"
        )
    return cleaned


def _valid_max_rating(value: int | None) -> int | None:
    if value is None:
        return None
    # bool — подкласс int: True прошёл бы как рейтинг 1.
    if isinstance(value, bool) or not isinstance(value, int):
        raise InvalidInput(f"max_rating должен быть целым числом; получено {value!r}")
    if not MIN_RATING_WINDOW <= value <= MAX_RATING_WINDOW:
        # rat_to=0 и отрицательные сайт молча игнорирует и отдаёт вершину
        # рейтинга: курсор 0 вернул бы модель в начало списка. Замерено.
        raise InvalidInput(
            f"max_rating должен быть от {MIN_RATING_WINDOW} до {MAX_RATING_WINDOW}; получено {value}"
        )
    return value

@_reporting
def get_head_to_head(player_id: str, opponent_id: str) -> dict:
    """Встречи игрока с конкретным соперником. Один запрос — профиль игрока.

    Инструмент закрытой категории (очные встречи, /rivals в robots.txt);
    виден только при поднятом RTTF_MCP_ALLOW_RESTRICTED. Раздел «соперники»
    сайта не запрашивается: встречи отбираются из разрешённого профиля.

    ОХВАТ НЕПОЛНЫЙ, и это ограничение источника, а не отсутствие встреч:
    просматриваются только последние турниры игрока (не больше десяти по
    каждой категории) и десять его лучших побед. Пустые списки означают
    «в этих турнирах не встречались», а не «не встречались никогда».
    coverage показывает, сколько турниров просмотрено и есть ли более
    ранние.

    singles — одиночные матчи, doubles — парные, где соперник был в
    противоположной паре; поля матчей как в get_player_matches, плюс
    tournament_id, date и hall_name турнира. best_wins — победы над
    соперником из лучших побед, не вошедшие в singles.
    """
    player_id = _valid_id(player_id, "player_id")
    opponent_id = _valid_id(opponent_id, "opponent_id")
    if player_id == opponent_id:
        raise InvalidInput("player_id и opponent_id совпадают")
    profile = _fetch_player(player_id, include_matches=True)
    context_keys = ("tournament_id", "date", "hall_name")
    found: dict[str, list] = {"s": [], "d": []}
    coverage = {}
    for code in MATCH_CATEGORIES:
        section = profile["categories"].get(code)
        tournaments = section["recent_tournaments"] if section else []
        coverage[code] = {
            "tournaments_checked": len(tournaments),
            "truncated": bool(section and section["recent_tournaments_truncated"]),
        }
        for entry in tournaments:
            for match in entry["matches"]:
                if code == "s":
                    hit = match["opponent_id"] == opponent_id
                else:
                    hit = any(p["player_id"] == opponent_id for p in match["opponents"])
                if hit:
                    found[code].append({key: entry[key] for key in context_keys} | match)
    seen = {m["tournament_id"] for m in found["s"]}
    best = [
        win
        for win in profile["best_wins"]
        if win["opponent_id"] == opponent_id and win["tournament_id"] not in seen
    ]
    return {
        "player_id": player_id,
        "opponent_id": opponent_id,
        "singles": found["s"],
        "doubles": found["d"],
        "best_wins": best,
        "coverage": {"singles": coverage["s"], "doubles": coverage["d"], "best_wins_checked": len(profile["best_wins"])},
    }

    average_rating и coefficient равны null.

    registered / registration_limit — сколько заявилось и лимит заявок
    (null, если лимита нет). У парного турнира сайт считает заявки
    парами.

    Одиночная таблица: place, player_id, name (как на сайте, с логином в
    скобках), city, rating_before_event, rating_delta, rating_after_event —
    рейтинги до и после ЭТОГО турнира, а не сегодняшние; wins/losses —
    встречи, sets_won/sets_lost — партии.

    Парная таблица: place, pair — два игрока с одиночными рейтингами на
    момент турнира, pair_rating_at_event — их сумма, wins/losses,
    sets_won/sets_lost. Дельты и рейтинга после у пар сайт не публикует.

    average_rating — средний рейтинг участников с двумя знаками: сайт
    считает его по внутренним дробным рейтингам, поэтому среднее целых из
    таблицы с ним точно не совпадёт. coefficient — коэффициент турнира
    (у парных null).
    """
    tournament_id = _valid_id(tournament_id, "tournament_id")
    html = _client.get_html(f"/tournaments/{tournament_id}")
    return parse_tournament(html, tournament_id)


@_reporting
def list_players(city: str = "", max_rating: int | None = None) -> dict:
    """Листает рейтинг игроков rttf.ru окнами по сто строк. Один запрос.

    Это единственный разрешённый способ выйти на игрока без поиска по
    имени (поиск сайт закрыл в robots.txt). Строки идут по убыванию
    рейтинга.

    city — код региона ("r77" — Москва и МО, "r78" — Санкт-Петербург и ЛО)
    или числовой код города ("1" — Москва, "2" — Санкт-Петербург); коды
    видны в ссылках городов на сайте и в поле city.city_id ответа. Пусто —
    вся страна.

    max_rating — верхняя граница окна (от 1 до 4000). Первый вызов — без
    неё; следующий — с max_rating из next_max_rating ответа. Соседние окна
    ПЕРЕКРЫВАЮТСЯ: сайт сравнивает границу с внутренним дробным рейтингом,
    а показывает округлённый, и без перекрытия часть игроков выпадала бы.
    Повторы между окнами отбрасывайте по player_id.

    next_max_rating равно null, когда список кончился (строк меньше ста)
    или когда stalled_on_tie равно true: сто строк окна имеют один и тот же
    рейтинг, и дальше окнами не пройти — остальные игроки с этим рейтингом
    через разрешённые адреса недоступны. Игроки с рейтингом ниже 1 тоже
    недоступны: такое окно сайт молча игнорирует.

    rank — место в ОБЩЕМ рейтинге, даже при фильтре по городу. is_team —
    корпоративная команда, а не человек: сайт ставит их в общий рейтинг
    наравне с игроками. city равно null, если город не указан. updated —
    дата последнего изменения рейтинга.
    """
    params: dict[str, str] = {}
    city_code = _valid_city(city)
    window = _valid_max_rating(max_rating)
    if city_code is not None:
        params["cities[]"] = city_code
    if window is not None:
        params["rat_to"] = str(window)
    html = _client.get_html("/players/", params)
    return {"city": city_code, "max_rating": window} | parse_players_list(html, window)


@_reporting
def search_tournaments(city: str = "", hall_id: str = "", tournament_type: str = "") -> dict:
    """Ближайшие и недавние турниры rttf.ru по фильтрам. Один запрос.

    Фильтра по датам и по названию нет: сайт закрыл оба в robots.txt.
    Доступны: city (как в list_players), hall_id (число из адреса зала,
    rttf.ru/halls/1073) и tournament_type — один из кодов сайта: s
    одиночные, d парные, t командные, p пинг-понг, r ракетлон, w шах-понг,
    v ветеранские, c детские, l лесенки, h форовые, m мини-теннис, t2/t3/t4
    триатлон, d12 дуатлон.

    upcoming — ближайшие турниры, past — прошедшие, от свежих к старым; в
    каждом списке не больше ста строк, листания нет (подгрузка на сайте
    идёт через закрытый адрес). Без фильтров сто прошедших покрывают
    примерно полтора дня; с фильтром по залу — несколько недель.
    *_total — счётчик «итого» сайта, если он показан (в коротких
    отфильтрованных списках), иначе null. *_truncated равно true, когда
    строк на сайте больше, чем в ответе.

    Строка: tournament_id, date, start_time, limit, hall_name (краткое имя
    зала), doubles, ladder (лесенка), live (идёт сейчас), registration_open,
    average_rating (null, если сайт не посчитал), registered /
    registration_limit, games (сыграно встреч или null).
    """
    params: dict[str, str] = {}
    city_code = _valid_city(city)
    if city_code is not None:
        params["cities[]"] = city_code
    if hall_id:
        params["halls[]"] = _valid_id(hall_id, "hall_id")
    if tournament_type:
        if tournament_type not in TOURNAMENT_TYPES:
            raise InvalidInput(
                f"tournament_type должен быть одним из {sorted(TOURNAMENT_TYPES)}; получено {tournament_type!r}"
            )
        params["types[]"] = tournament_type
    html = _client.get_html("/tournaments/", params)
    return {"filters": params} | parse_tournaments_list(html)


@_reporting
def get_hall(hall_id: str) -> dict:
    """Зал (клуб) rttf.ru. Один запрос.

    hall_id — число из адреса зала (rttf.ru/halls/1073); оно же приходит в
    get_tournament (hall.hall_id) и в сводке игрока
    (stats.most_frequent_hall.hall_id).

    Поля: name, address, metro (список станций или null), opening_hours,
    tables — число столов, website, amenities и paid_amenities — удобства,
    бесплатные и платные, rating — оценка посетителей (overall и по
    аспектам) или null, representative_player_id — профиль представителя
    зала на сайте. Любое поле может быть null, если зал его не заполнил.

    Контакты зала не отдаются намеренно: там личные телефоны сотрудников.
    Турниры зала — search_tournaments(hall_id=...).
    """
    hall_id = _valid_id(hall_id, "hall_id")
    html = _client.get_html(f"/halls/{hall_id}")
    return parse_hall(html, hall_id)


TOOLS = {
    "get_player": get_player,
    "get_player_matches": get_player_matches,
    "get_head_to_head": get_head_to_head,
    "get_tournament": get_tournament,
    "list_players": list_players,
    "search_tournaments": search_tournaments,
    "get_hall": get_hall,
}


def build_server(allow_restricted: bool) -> MCPServer:
    # Версия берётся из метаданных пакета, а не дублируется строкой: иначе
    # она разъедется с pyproject, и клиент покажет неверную.
    server = MCPServer("rttf", version=version("rttf-mcp"))
    for name in tools_to_register(TOOLS, allow_restricted):
        description = None
        if name == "get_player":
            note = _GET_PLAYER_ON if allow_restricted else _GET_PLAYER_OFF
            description = (get_player.__doc__ or "").rstrip() + note
        server.add_tool(TOOLS[name], name=name, description=description)
    return server


mcp = build_server(restricted_allowed())


def main() -> None:
    mcp.run()


if __name__ == "__main__":
    main()

# rttf-mcp

MCP-сервер для доступа к рейтингу настольного тенниса
[rttf.ru](https://rttf.ru): игроки, турниры, залы.

Тонкая прослойка получения данных. Сервер не считает аналитику, не хранит
состояние и не кэширует — всю интерпретацию делает модель над JSON.

## Что сервер читает, а что нет

`robots.txt` rttf.ru поимённо закрывает матчи (`/games`, `/results`),
очные встречи (`/rivals`), поиск по имени (`?name=`, `/search`) и фильтры
по датам. Сервер **никогда** не запрашивает закрытые адреса: клиент
сверяет каждый запрос, включая шаги перенаправления, со списком правил и
отказывает до обращения к сети.

Часть закрытой категории — матчи последних турниров — лежит на
разрешённой странице профиля. Извлекать её или нет, решает переменная
окружения:

| `RTTF_MCP_ALLOW_RESTRICTED` | Что видит модель |
| --- | --- |
| не задана, `0`, `false`, `no`, `off` | только уровень турнира и выше; описание `get_player` прямо говорит, что матчей нет по настройке, а не на сайте |
| `1`, `true`, `yes`, `on` | ещё `get_player_matches` и `get_head_to_head` |
| что-то другое | сервер не запускается |

Поиска по имени нет ни в каком режиме: разрешённого пути к нему у сайта
нет.

## Инструменты

| Инструмент | Что возвращает |
| --- | --- |
| `get_player(player_id)` | категории рейтинга (одиночный, пары, ФНТР), история рейтинга, сводка, до 10 последних турниров с местом и балансом |
| `get_tournament(tournament_id)` | метаданные и итоговая таблица (рейтинг до, дельта, после) |
| `list_players(city="", max_rating=None)` | рейтинг окнами по 100 строк; курсор `next_max_rating` |
| `search_tournaments(city="", hall_id="", tournament_type="")` | ближайшие и недавние турниры, по 100 строк |
| `get_hall(hall_id)` | зал: адрес, часы, столы, удобства, оценка; без контактов |
| `get_player_matches(player_id, category="s")` | *только с флагом*: матчи последних турниров и лучшие победы |
| `get_head_to_head(player_id, opponent_id)` | *только с флагом*: встречи с соперником в последних турнирах |

Каждый инструмент делает ровно один запрос к сайту. Идентификаторы —
числа из адресной строки: `rttf.ru/players/28415`.
